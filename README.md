# 알아서

**일단 써. 나머진 알아서.**

월급과 카드값, 통장 잔액을 한곳에서 보고 내가 쓰는 AI와 함께 다음 달을 정리하는 개인 재무 도구입니다.

가계부에 거래를 옮겨 적는 일보다 어려운 건 그다음이었습니다. 이번 달에 얼마를 썼는지는 카드 앱에서 볼 수 있지만, 지금 통장에 남은 돈으로 미납 카드값을 먼저 내도 되는지, 큰 지출은 몇 달로 나누는 편이 나은지, 내가 포기하고 싶지 않은 소비까지 반영하면 예산을 어떻게 다시 짜야 하는지는 따로 계산해야 했습니다.

이 앱은 그 판단을 한 화면에 모으려고 시작했습니다. 카드 승인 내역과 계좌 입출금을 함께 보고, 소득과 월급일, 현재 잔액, 고정비, 소비 성향을 반영해 계획을 만듭니다. 사용자가 “취미비는 줄이지 말고 나머지에서 조정해 줘”처럼 말하면 그 조건을 지키면서 배분을 다시 계산합니다.

## 왜 만들었나

기존 금융 앱은 이미 일어난 일을 잘 보여줍니다. 지출 합계와 카테고리도 정리해 줍니다. 하지만 개인마다 다른 기준을 계속 반영하기는 어렵습니다. 같은 10만 원도 누구에게는 줄여야 할 소비이고, 누구에게는 꼭 남겨두고 싶은 생활비입니다.

AI를 쓰면서 이 간격을 줄일 수 있다고 느꼈습니다. 정해진 설문으로 생활 방식을 맞추는 대신 평소 말하듯 조건을 설명하고, 실제 거래와 소득을 근거로 계획을 고치게 하는 방식입니다. 개인화가 추천 문구에 머무르지 않고 내 돈의 흐름과 선택 기준까지 이어졌으면 했습니다.

처음에는 개인용으로 만들었습니다. 직접 써 보니 비슷한 불편을 겪는 사람도 자기 데이터와 자기 AI로 사용할 수 있겠다는 생각이 들었습니다. 그래서 소유자의 금융 자료와 인증정보는 빼고, 각자 로컬에서 연결해 쓰는 형태로 공개합니다.

## 만드는 과정에서 부딪힌 문제

### 카드사에는 에이전트용 통로가 없었다

카드사가 개인 에이전트용 MCP나 지속 연결 API를 제공하는 구조는 아니었습니다. 웹 로그인은 추가 인증과 세션 만료가 있고, 브라우저 화면은 언제든 바뀔 수 있습니다.

그래서 한 가지 수집 방식에 기대지 않았습니다. 현재는 거래 파일 가져오기, CODEF 계좌 조회, 카드 승인내역 변환 도구를 제공합니다. 연결이 가능한 자료는 동기화하고, 그렇지 않은 자료는 표준 JSON으로 가져옵니다. 웹 화면 자동 수집은 검증되지 않은 상태에서 지원한다고 적지 않습니다.

### 납부 상태는 승인내역만으로 확정할 수 없었다

카드 승인내역에 거래가 있다고 해서 미납인지, 이미 선납했는지 바로 알 수 있는 것은 아닙니다. 즉시결제 목록에서 사라졌다는 사실만으로 납부 완료라고 단정하는 것도 위험했습니다.

이 앱은 납부를 확인할 근거가 있을 때만 `납부 확인`으로 표시합니다. 확인되지 않은 건은 미납으로 다루고 먼저 확인하도록 안내합니다. 결제나 출금을 대신 실행하지는 않습니다.

### 카드와 계좌를 합치면 같은 지출이 두 번 잡혔다

카드 승인 금액과 나중에 빠져나간 카드대금은 서로 다른 거래처럼 보이지만 같은 소비에서 나온 돈입니다. 두 금액을 단순히 더하면 월 지출이 부풀어 오릅니다.

장부에서는 카드와 계좌를 함께 보여주되 계산 역할을 나눴습니다. 카드 내역은 소비 분석에, 계좌 내역은 잔액과 현금흐름 파악에 씁니다. 입금, 출금, 선납, 미납, 계좌, 카드 필터로 필요한 흐름만 따로 볼 수 있습니다.

### 자연어는 유연하지만 금액 계산까지 맡기면 흔들렸다

AI는 “저축은 건드리지 말고 생활비를 조금 늘려 줘” 같은 문장을 이해하는 데 유용합니다. 반면 정확한 금액 배분과 상태 변경까지 모델 응답에 맡기면 같은 요청에도 결과가 달라질 수 있습니다.

그래서 AI와 코드의 역할을 분리했습니다. AI는 의도, 거래 분류, 큰 지출 후보와 근거를 정리합니다. 실제 금액 계산과 데이터 변경은 서버가 정해진 규칙으로 처리합니다. 자연어 요청은 변경안으로 먼저 만들고, 적용 전후를 확인한 다음 저장합니다.

### 모델 비용을 서비스 운영자가 대신 부담하고 싶지 않았다

대시보드에 AI를 넣으려면 보통 서비스가 API 비용을 부담하거나 사용자에게 새 API 키를 요구합니다. 개인 프로젝트를 공개하면서 중앙 서버가 금융 맥락을 모으고 모델 비용까지 떠안는 구조는 맞지 않았습니다.

이 앱은 세 가지 연결 방식을 둡니다.

| 연결 방식 | 쓰는 경우 |
| --- | --- |
| Codex / OpenCodex | 이미 쓰고 있는 ChatGPT 구독 로그인을 그대로 활용하고 싶을 때 |
| OpenAI / Anthropic API | 별도 API 키와 원하는 모델을 직접 선택할 때 |
| MCP | Claude, Codex 등 MCP를 지원하는 외부 AI 앱에서 같은 로컬 재무 자료를 다룰 때 |

앱에서 쓰던 AI를 연결할 수 있게 한 이유도 여기에 있습니다. 이미 비용을 내고 사용하는 AI가 있다면 별도 API 사용료 때문에 기능을 포기할 필요가 없습니다. 어떤 AI를 쓸지는 사용자가 고르고, 재무 데이터는 이 프로젝트의 로컬 저장소에 남깁니다. 구독 한도가 끝났다고 유료 API로 몰래 전환하지도 않습니다.

## AI를 대시보드 안에 둔 이유

대화창만 있으면 사용자가 매번 무엇을 물어볼지 먼저 생각해야 합니다. 이 앱의 AI는 자료가 바뀌면 거래를 분류하고, 소득에 비해 큰 지출과 확인할 미납 건을 먼저 꺼냅니다. 분석 결과는 대시보드에 계속 남아 있으므로 다시 질문하지 않아도 확인할 수 있습니다.

대화는 계획을 개인화하는 데 씁니다. 예산에서 빼고 싶지 않은 소비, 이번 달만 적용할 조건, 앞으로 계속 지킬 기준을 자연어로 남길 수 있습니다. 직접 입력한 값과 대화로 정한 값은 같은 계획 데이터에 반영됩니다.

## 지금 할 수 있는 일

- 세전 연봉 입력 후 예상 실수령액 확인, 실제 월 실수령액으로 교체
- 월급일과 현재 잔액을 반영한 월간 배분
- 카드 승인내역과 계좌 입출금 통합 장부 및 조건별 필터
- AI 거래 분류, 지출 흐름 분석, 큰 지출 우선 검토
- 사용자가 남기고 싶은 소비를 반영한 예산 재배분
- 확인된 조건 안에서 일시불과 할부 부담 비교
- 제품 링크, 이미지, 목표 금액, 모은 금액을 포함한 구매 목표 관리
- CODEF 계좌 연결과 마스킹된 잔액·입출금 동기화
- Codex, OpenCodex, OpenAI API, Anthropic API, MCP 연결

## 실행

Node.js 24 이상이 필요합니다.

```sh
npm ci
npm run build
npm start
```

브라우저에서 `http://127.0.0.1:4317`을 엽니다. 개발 모드는 `npm run dev`입니다.

## AI 연결

설정 화면에서 연결 방식을 고릅니다.

- Codex 구독은 공식 CLI 설치 후 `ChatGPT로 로그인`을 사용합니다. OpenCodex가 실행 중이면 허용된 로컬 프록시를 감지해 그 연결을 사용합니다.
- OpenAI와 Anthropic은 API 키와 모델을 직접 선택합니다. API 키는 서버 메모리에만 두며 재시작하면 사라집니다.
- MCP는 설정 화면에서 복사한 stdio 구성을 지원 앱에 등록합니다. 직접 실행하려면 `npm run mcp`를 사용합니다.

대화와 분석에는 소득, 계획, 최근 거래가 선택한 AI 제공사로 전달될 수 있습니다. 계좌번호는 끝 4자리만 전달하며, 계좌 자료 사용 여부는 사용자가 정합니다.

## 금융 자료 연결

계좌 조회는 CODEF Client ID, Client Secret, Public Key가 필요합니다. 인터넷뱅킹 ID, 공동인증서, 빠른조회 중 은행이 지원하는 방식으로 계좌를 등록할 수 있습니다. 인증 비밀번호와 인증서 파일은 등록 요청이 끝난 뒤 보관하지 않습니다.

카드 승인내역은 일반 거래 JSON이나 CODEF 응답 파일로 가져올 수 있습니다. 수동 변환 도구는 다음처럼 실행합니다.

```sh
node codef-fetch.cjs 새파일.json
```

필요한 환경변수와 기관별 입력값은 CODEF 발급 정보에 맞춰 직접 설정해야 합니다. 인증값을 소스, 채팅, 커밋에 넣지 마세요.

## 데이터와 보안

이 프로젝트는 단일 사용자 로컬 앱입니다. 데이터는 기본적으로 `.private/finance.sqlite`에 저장되고 Git과 웹 정적 경로에서 제외됩니다. CODEF 연결값은 SQLite 옆 암호화 파일에 보관하며 계좌번호는 해시 식별자와 끝 4자리로 바꿔 저장합니다.

개발 서버도 `.private`, DB, 키 파일을 제공하지 않습니다. 외부 화면 삽입을 차단하고 `127.0.0.1`에서만 실행합니다. 로컬 OS 계정과 연결한 AI 앱은 사용자가 신뢰해야 하는 별도 경계입니다.

## 하지 않는 일

이 앱은 이체, 출금, 카드 결제, 할부 전환을 자동 실행하지 않습니다. 투자·적금 상품의 실시간 추천도 아직 제공하지 않습니다. 할부 판단은 "3개월까지 무이자, 그 이상은 연 15% 수수료"라는 기본 가정으로 서버가 계산하고(지금 잔액 → 다음 달 월급 → 3개월 무이자 → 저축 조금 줄여 일시불 → 6·12개월 → 예산 조정 순), 모델은 그 결론의 이유만 씁니다. 실제 카드사 조건은 확인하지 않으며 자료가 일부 기간뿐이면 한 달 전체 소비처럼 설명하지 않습니다.

지금은 완성된 금융 서비스보다 실제로 쓰면서 판단 기준을 다듬는 개인 도구에 가깝습니다. 각자 자신의 데이터와 AI를 연결해 써 보고, 필요한 부분을 함께 고칠 수 있도록 공개했습니다.
